# Python - Everything is Object

This project explores how Python handles objects, values, references, assignment, aliases, and mutability. It focuses on understanding the difference between mutable and immutable objects, object identity, equality, and how variables reference objects. The tasks also examine how Python passes objects to functions and how cloning differs from aliasing. Through these exercises, I will strengthen my understanding of Python's object model and develop the reasoning skills needed to explain Python behavior clearly without relying on external resources.
