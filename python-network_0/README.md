# Python - Network #0

This project introduces fundamental concepts of networking and HTTP using Python and Bash. It covers URLs, HTTP requests and responses, headers, status codes, cookies, and the use of cURL for interacting with web servers. The tasks provide practical experience with sending requests, retrieving response information, and understanding communication between clients and servers. The project also reinforces scripting practices, Python documentation, executable files, and code style while developing a stronger understanding of how web applications communicate.
