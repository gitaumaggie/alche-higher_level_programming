PYTHON-HELLO WORLD
This project introduces the basics of python programming and involves performing different tasks related to basics of python programming.

By completing the project , I learn how to:

- Run Python scripts using the Python interpreter
- Run Python code from the command line
- Use the `print()` function
- Work with strings and integers
- Use variables
- Use f-strings
- Understand Python coding style and `pycodestyle`


REQUIREMENTS
 1. Python3
 2. Ubuntu 20.04
 3. git and github
