# SQL - More Queries

This project introduces advanced SQL concepts using MySQL. The tasks focus on managing users and privileges, defining database constraints, retrieving information from multiple tables, and working with subqueries, joins, and unions. The project also develops practical skills in writing SQL scripts that follow strict formatting and syntax requirements. Each script is designed to demonstrate a specific SQL concept while maintaining clear comments, uppercase SQL keywords, proper file structure, and compatibility with the MySQL 8.0 environment.
