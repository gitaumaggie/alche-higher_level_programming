 PYTHON- DATA STRUCTURES: LISTS, TUPLES

This project contains tasks that help in understanding how python stores and manages collectionof data. The project helps one learn how to create , access, modify and manipulate lists using common methods , as well as use lists as stacks and queues. The project also introduces comprehensions, tuples, sequences, tuple packing, sequence unpacking and the del statement.

REQUIREMENTS:
1. python3
2. git and github
3. ubuntu 20.04
