# JavaScript Warm-Up

## About

This project is part of my Software Engineering learning journey at Africa Leadership College of Higher Education (ALCHE).

The JavaScript Warm-Up project introduces fundamental JavaScript concepts through practical coding exercises. The tasks are designed to help me understand how JavaScript works, how to write executable scripts using Node.js, and how to apply programming concepts to solve problems.

## Learning Objectives

Through this project, I aim to understand and practice:

- Why JavaScript is important in web development
- How to run JavaScript scripts using Node.js
- Variables and constants
- The differences between `var`, `let`, and `const`
- JavaScript data types
- Conditional statements
- Loops
- Functions
- Scope
- Arithmetic operators
- Manipulating dictionaries and objects
- Importing files and modules

## Technologies

- JavaScript
- Node.js
- Ubuntu/Linux
- Semistandard

## Requirements

- Node.js 14.x
- Ubuntu 20.04 LTS
- JavaScript files must begin with the Node.js shebang:
  `#!/usr/bin/node`
- All files must end with a new line
- All JavaScript files must be executable
- Code must follow Semistandard style guidelines

## Project Structure

The project contains JavaScript scripts, with each file focusing on a specific programming concept or task.

## Running the Scripts

To execute a JavaScript file:

./filename.js


Alternatively, using Node.js:


node filename.js
