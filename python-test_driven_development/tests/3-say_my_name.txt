
========================
Say my name
========================

This module prints a person's first and last names.
Both arguments must be strings.

Import the function:

>>> say_my_name = __import__('3-say_my_name').say_my_name

Test two ordinary names:

>>> say_my_name("John", "Smith")
My name is John Smith

>>> say_my_name("Walter", "White")
My name is Walter White

Test the default last name:

>>> say_my_name("Bob")
My name is Bob 

Test an empty first name:

>>> say_my_name("", "Smith")
My name is  Smith

Test an empty last name:

>>> say_my_name("Margaret", "")
My name is Margaret 

Test both names as empty strings:

>>> say_my_name("", "")
My name is  

Test names containing spaces:

>>> say_my_name("Mary Jane", "Watson")
My name is Mary Jane Watson
