
========================
Print square
========================

This module prints a square using the # character.
The size must be a non-negative integer.

Import the function:

>>> print_square = __import__('4-print_square').print_square

Print a square of size four:

>>> print_square(4)
####
####
####
####

Print a square of size three:

>>> print_square(3)
###
###
###

Print a square of size one:

>>> print_square(1)
#

A square of size zero produces no output:

>>> print_square(0)
